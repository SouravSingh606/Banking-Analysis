# 🏦 Banking Data Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing banking data to identify meaningful patterns, trends, and business insights.

The project combines **Python, Excel, Power BI, and data visualization** techniques to explore banking-related data and present the results through analytical reports and interactive dashboards.

## 🎯 Project Objectives

* Analyze banking customer and transaction data
* Perform data cleaning and preparation
* Explore important patterns and trends
* Generate meaningful business insights
* Create interactive dashboards
* Present analytical findings in a clear and understandable format

## 🔍 Analysis Process

### 1. Data Collection

Banking datasets are used as the source for the analysis.

### 2. Data Cleaning

The data is prepared for analysis by checking and handling:

* Missing values
* Duplicate records
* Inconsistent data
* Data types
* Unnecessary columns

### 3. Exploratory Data Analysis

Python is used to explore the data and identify patterns and relationships within the banking dataset.

The analysis includes:

* Customer analysis
* Banking activity analysis
* Transaction-related analysis
* Data distribution
* Trends and patterns

### 4. Data Visualization

Visualizations are created using Python libraries such as **Matplotlib** and **Seaborn** to make the findings easier to understand.

### 5. Dashboard Development

The analyzed data is presented through **Power BI dashboards** to provide an interactive view of the results.

## 🚀 How to Use the Project

### Python Analysis

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open either:

```text
BankEDA (Version 1).ipynb
```

or

```text
BankEDA (Version 2).ipynb
```

4. Run the notebook cells sequentially.

### Power BI Dashboard

Open the `.pbix` file using **Microsoft Power BI Desktop**.
